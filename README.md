## Personal Portfolio Landing Page
A responsive one-page developer portfolio built for **InternCircle: Fullstack Web Development, Project 1**.

---

### Features
- Semantic HTML5 structure (`header`, `nav`, `main`, `section`, `footer`)
- Flexbox for the navigation bar and hero section
- CSS Grid (`auto-fit`) for the skills and project cards
- Mobile-responsive design with a media query below 700px
- Smooth scrolling, hover effects and visible keyboard focus styles
- Skip link, alt text and good colour contrast for accessibility
- Downloadable resume

---

### Built with
- HTML5
- CSS3 (Flexbox, Grid, custom properties, media queries)
- Google Fonts (Fraunces and Manrope)

### Run locally
1. Clone the repository:
   ```
   git clone https://github.com/Keerthana-webdev/personal-portfolio-landing-page.git
   ```
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**, or open the file directly in a browser.
